# astrbot_plugin_doudizhu

在 QQ 群里和群友斗地主。移植自 mirai-console 插件
[kono-dada/doudizhu](https://github.com/kono-dada/doudizhu)（v1.1，Kotlin 版），
逻辑（牌型、倍率、抢地主、结算、每日低保）保持一致，交互方式改成 AstrBot 的消息驱动。

- 由天影大侠和Deepseek共同移植到astrbot并添加新功能。

所有指令都是**中文、不带 `/` 前缀**，不占用 AstrBot 的唤醒前缀，避免和其他机器人、
QQ 官方指令抢指令。

## 安装

1. 把整个 `astrbot_plugin_doudizhu` 目录放进 AstrBot 的 `data/plugins/` 下；
2. 在 WebUI 的「插件」页面点击重载（或重启 AstrBot）；
3. 在插件配置里按需调整底分、初始积分、回合超时等（见下表）。

无第三方依赖，不需要 `requirements.txt`。

## 平台支持

| 平台 | 群内对局 | 私聊发牌 |
| --- | --- | --- |
| QQ（aiocqhttp / NapCat） | ✅ | ✅ 发牌时自动私聊 |
| Telegram | ✅（论坛话题按话题分桌） | ✅ 发牌时自动私聊 |
| Discord | ✅（每个频道一桌） | ⚠️ 主动私聊发牌发不出去（Discord 私聊频道 id ≠ 用户 id），玩家私聊 bot 发「我的牌」即可拿到手牌 |
| KOOK / Slack / 飞书等 | ✅ | 看适配器：私聊会话 id 等于用户 id 就能自动发 |

说明：

- 群内逻辑（口令识别、出牌、结算、@提醒）与平台无关，走的是 AstrBot 的会话机制；
- 私聊回复优先走「当前私聊会话」，所以 Discord 上玩家主动私聊 bot 发「我的牌」/「出3」都能用；
- 建议保持 AstrBot 的 `platform_settings.unique_session = false`，否则群会话 id 会带用户后缀，主动发群消息可能路由不到；
- Telegram 的 @ 会被适配器退化成纯文本前缀，不影响使用；不支持的平台会自动退回纯文本发送。

## 玩法

群里按顺序发送：

| 步骤 | 消息 | 说明 |
| --- | --- | --- |
| 1 | `创建游戏` | 开一桌，底分默认 200 |
| 2 | `上桌` | 满 3 人才能开始；`下桌` 可退出（未开始前） |
| 3 | `开始游戏` | 发牌，bot 私聊给每个人自己的 17 张牌 |
| 4 | `抢地主` / `不抢` | 按上桌顺序询问，第一个「抢」的人当地主并拿到底牌 |
| 5 | `出34567` | 出牌。以「出」开头，牌面写法见下 |
| 5 | `要不起` | 过牌（也可以发 `不要`、`过`） |
| 6 | —— | 出完手牌即获胜，自动结算积分 |

其他：`当前玩家`（看牌局状态）、`我的牌`（私聊重发手牌）、`乞讨`（领每日低保）、
`斗地主余额`（积分与胜率）、`斗地主帮助`（玩法说明）、
`结束游戏`（仅管理员，强制结束本局）、`送钱@某人`（仅主人，固定 500 积分）。

### 牌面写法

- 3-9、10、J、Q、K、A、2、鬼（小王）、王（大王）；
- 大小写不敏感，`10` 也可以写成 `T`，牌之间可以有空格，如 `出 10 J Q K A`；
- 例子：
  - 单张 `出3`、对子 `出33`、三张 `出333`
  - 三带一 `出3334`、三带二 `出33344`
  - 顺子 `出34567`、连对 `出334455`、飞机 `出33344456`
  - 炸弹 `出3333`、王炸 `出鬼王`
  - 四带二 `出333345`、四带两对 `出33334455`

抢到地主、炸弹出现时倍率 ×2，结算时积分 = 底分 × 倍率。

### 积分

- `乞讨`：每日低保，默认 500 积分（每天一次），群聊或私聊都行；
- `斗地主余额`：查看自己的积分、总场次、胜场与胜率；
- `斗地主帮助`：玩法说明；
- `送钱@某人`：主人专用，给指定玩家加 500 积分（固定值）；
- 新玩家第一次参与时发放 `initial_coins`（默认 500）。

### 斜杠指令（可关闭）

除了中文口令，也保留了传统的斜杠写法，等价于上面的口令：

| 斜杠指令 | 等价口令 |
| --- | --- |
| `/d beg` | `乞讨` |
| `/d me` | `斗地主余额` |
| `/d help` | `斗地主帮助` |

这些斜杠指令全部受配置项 **`enable_slash_commands`** 控制：把它关掉后，
插件不再提供任何 `/` 入口（`/d` 光杆也不会再触发指令树），只走中文口令，
从而完全避开与其它机器人、QQ 官方指令的前缀冲突。

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enable_slash_commands` | bool | true | 是否提供 `/d beg`、`/d me`、`/d help`；关掉后插件不再占用 `/` 前缀 |
| `basic_bet` | int | 200 | 底分，也是上桌门槛 |
| `initial_coins` | int | 500 | 新玩家初始积分 |
| `daily_allowance` | int | 500 | `乞讨` 每日低保数量 |
| `turn_timeout` | int | 120 | 回合超时（秒），超时自动不抢/不出；0 表示不限时 |
| `allowed_groups` | list | `[]` | 允许开局的群号，空表示所有群 |
| `admin_ids` | list | `[]` | 额外管理员：可「结束游戏」和「送钱@某人」 |

## 与 mirai 原版的差异

保留：牌型判定、抢地主流程、炸弹翻倍、底分结算、每日低保、胜率统计。

改动（都是适配 AstrBot 或修 bug）：

- **交互**：原来用协程阻塞监听群消息，现在每条消息触发一次状态机；
  出牌从 `/34567` 改成 `出34567`，不再占用 `/` 唤醒前缀（避免和别的机器人、
  QQ 官方指令冲突）。
- **中文口令**：新增 `斗地主帮助`、`斗地主余额`、`乞讨` 等免前缀口令；
  原来的 `/d help`、`/d me`、`/d beg` 仍然保留，可由配置项
  `enable_slash_commands` 一次性全部关闭。
- **管理指令**：mirai 的控制台指令 `/dc addgroup`、`/dc addadmin` 改为插件配置项
  `allowed_groups`、`admin_ids`（AstrBot 没有控制台概念）。
- **王炸**：原版王炸无法压过普通炸弹（比较逻辑缺陷），现在王炸最大。
- **飞机带牌**：原版按输入顺序切分三张与翅膀，现在按牌值统计识别，支持
  `3334445566`（飞机带对）等写法。
- **四带两对**：新增支持。
- **超时托管**：新增回合超时，避免有人掉线后整局卡死。
- **口令化**：`乞讨`、`斗地主余额`、`斗地主帮助` 等中文口令与 `/d xxx` 并存，
  可用开关整体关掉斜杠入口。
- **数据**：积分用 AstrBot 插件 KV 存储（`data/config/` 下的插件 KV），
  不再写插件自身目录。
- **结算播报**：结算时同时公布三家剩余手牌，方便核对。
- **不能中途下桌**：开局后禁止 `下桌`（原版会导致手牌映射错乱）。

## 开发

纯逻辑在 `core/` 下，不依赖 AstrBot，可以直接跑测试：

```bash
python tests/test_cards.py   # 牌型解析与比较（19 个用例）
python tests/test_game.py    # 完整对局流程，含超时、结算、持久化（19 个用例）
```

再用 AstrBot 自带的 Python 环境跑一次冒烟测试（会真的 import `astrbot.api`、
注册 handler 和过滤器、走一遍完整流程）：

```bash
# 在 AstrBot 根目录执行（data 目录必须存在）
C:\Users\<你>\AppData\Roaming\uv\tools\astrbot\Scripts\python.exe ^
    data\plugins\astrbot_plugin_doudizhu\tests\test_astrbot_smoke.py
```

`main.py` 只做三件事：把 AstrBot 事件翻译成 `core` 的调用、把 `core` 的发言
交给 `Context.send_message`、注册中文口令与可关闭的 `/d` 指令。
